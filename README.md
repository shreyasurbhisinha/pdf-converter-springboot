# 📄 PDF Converter (Spring Boot)

##  Features
- Upload Word (.docx) files
- Convert to PDF
- Download converted PDF

##  Tech Stack
- Java
- Spring Boot
- LibreOffice

## 📂 Project Structure
pdfconverter/
├── controller/
├── service/
├── uploads/
├── outputs/
 ⚙️ How to Run

1. Clone the repo:
   git clone https://github.com/your-username/pdf-converter-springboot.git

2. Open in IntelliJ

3. Run the application

4. Use Postman:
   POST http://localhost:8080/api/upload
